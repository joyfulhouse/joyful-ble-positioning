# Brand provenance

The Joyful BLE Positioning mark is original project artwork created for this repository by
Bryan Li with Codex-assisted geometric construction on 2026-07-21. It combines an abstract
floor-plan grid, three receiver nodes, and a central observation point. It is not derived from
Home Assistant, the Bluetooth SIG, Bermuda, BPS, Pebblebee, or any other vendor artwork.

The editable source is `artwork/joyful-ble-positioning.svg`. The 512 × 512 source was rendered
to `custom_components/joyful_ble_positioning/brand/icon@2x.png`, then downsampled to the required
256 × 256 `brand/icon.png` with ImageMagick using an sRGB colorspace and Lanczos filtering.
